# 评测计划与边界

当前没有真实推理基准或性能结果。按详细实施计划 P2 建基线，P4/P5 逐项验证增强。

负载矩阵：低复用、稳定共享前缀、热点突发/迁移、长短输入输出混合、多轮依赖、超过缓存容量、失联/重启。公开数据与受控生成结合；数据许可、版本、种子和校准/评测拆分必须记录，不提前泄露未来请求。

指标：固定到达队列的 TTFT、客户端有效输出间隔、TPOT、成功完成率、SLO 达标容量、积压趋势、CPU/RSS 与控制成本。输出 chunk 间隔不冒充真实 token 间隔；错误和超时不能从分母剔除。

基线：直连、仅转发、强负载策略、成熟 cache-aware、增量策略；同底座消融与原系统整体对照分开。M8 比较无后台、仅观察、固定计划、动态计划。模型、设备、APC、输入输出设置保持一致，独占窗口内交替次序并重复测量。

只有差异大于噪声且正确性/退化约束成立才能宣称收益。主指标阈值在正式对比前冻结，不先编造“提高 xx%”。原始数据放 artifacts 或专用证据存储，Git 中保存配置、摘要和校验和。
