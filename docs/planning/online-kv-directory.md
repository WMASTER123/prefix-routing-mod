# 在线 KV 目录接线与集成门槛

日期：2026-10-14。基于 Router→真实 HUST 终态组合。当前实现先验证在线事件进入原索引，结果记录到独立 evidence；本计划不表示生产资格通过。

## 范围与来源

固定 HUST ced6857/b47795c 的原生三帧协议复用 M7 `adapters.kv`；M2 继续调用固定 Router 91b65ee 原索引及已有 Directory/Pool。不另造树、代理或设备同步。新增有限 stdio owner 仅用于实际接线与反例测试，之后生产宿主直接包含同一适配逻辑，不能将逐帧跨进程 JSON 当成最终请求热路径。

只接受独占启动、同机 loopback/私有 IPC、TP1/DP1、group0、full_attention、block128、FP16/eager 的空起点。原采集订阅在启动前连接；目录订阅在服务就绪后、任何业务请求前连接，以已有终态控制接口确认 frontend/core 及实例身份，以原生 replay 从0确认尚无发布事件。空缓存来源是受控启动及固定引擎路径，不是 END_SEQ 自身。已热服务接管不在此资格内。

原生流无 publisher epoch；本地会话 ID 只表示受控进程/连接绑定，不冒充后端 epoch。每次控制检查比对真实实例和 frontend/core PID，持有自有 backend 进程；换实例、断连、缺口、非法父链、协议/预算错误均撤销对应目录信任。普通新帧不能重新开启；M3 在途账本不受目录失效清空。

控制租约从索引 owner 发起检查的本地时刻计算，采用一次性控制票据，消息到达不续租。同一 socket owner 有界消费 live/replay，连续覆盖后确认已处理序号。原生 END_SEQ 仅标记本次重放结束，不提供排他快照/生产者队列清空证明；目录仅描述已发布、已处理的观测，不能声称与设备实时强一致。

## 验收和资源

- 请求进行期间持续消费事件，查询调用同一个长驻原索引，不重新读取离线 trace。
- M1 使用相同本地模型 tokenizer/template 的完整 token block digest；未观测为 unknown，可信空目录为0。只计完整连续匹配，不把计划或请求历史写成驻留。
- 原 Pool 限制分区数与各分区逻辑额度之和；Directory 继续限制记录、父链深度、批操作、重建 overlap 和查询长度。逻辑预算不是 allocator RSS 硬保证。
- CPU 覆盖双分区、错误身份、父链缺失、坏批尾、重复冲突、序号缺口、租约失效、断连及满额，查询不能见到半批视图。
- 真机先两卡顺序受控实例接线；随后资源允许时两个 TP1 同时启动，复用原 HTTP Router 做组合与配对开销。当前8核/64GiB Host 是独立风险，需记录峰值和压测端负载。
