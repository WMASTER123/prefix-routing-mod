# ADR：先验证逻辑终态与有界投递，不直接安装新 observer

状态：用户批准小范围 CPU 评估；生产接线未冻结。日期：2026-10-12。

## 问题与证据

固定 HUST 普通取消只发输入消息；核心清理返回列表未直接回传，DP finished-set 也不是单副本通用对账接口。stop string 在核心取消前移除前端映射；异步取消可能先结束请求再延迟释放 blocks。HTTP 完成不能替代可靠终态。

## 决定

先在显式 CPU 工具中执行固定源码方法，评估提前保留完整关联、成功清理后观测，以及有限 journal 到现有参考账本的在线更新。不改变 component-v0.1 类型，不安装插件、不修改 HUST 源码或设备执行。详细[范围和成本](../planning/terminal-observer-scope.md)。

不用每请求暂停/排空服务换取确认；不强开内部 DP 模式；不把 EOF、超时、observer 重启或空快照当结束。核心逻辑结束只支持请求账本候选语义，不能修改缓存目录或物理空闲计数。

## 代价与退出条件

必须解决真实父子请求封口、结果与逻辑结束区分、单一生命周期序号、跨进程 ACK/恢复、长期留存和 Router 整进程重启。现原型保留 tombstones，满额拒绝；无法长期使用。CPU 消费者重建保留账本，不是持久化。

若关联/观测需要改动大范围调度、请求生成链或引擎 fork，停止安装并讨论；若有限热路径开销或恢复成本不能接受，重新评估宿主接口，不隐瞒保守账本长期饱和问题。方法级 pass 不放行 NPU/生产。完成这些接线再进入 M7→M2 和首版生产接口冻结。
