# ADR：有界目录与流式资源的 CPU 适配实验

状态：实验方案，生产接口待验证及另一成员审查。日期：2026-10-12。

## 问题与证据

固定 Router 91b65ee 的索引移除驻留后保留 anchors；上轮唯一块更替实验已观察历史内存增长。HTTP 流路径使用无界队列，客户端 drop 的本地生命周期证据不能说明 producer 或后端已经停止。本轮先验证这两个影响复用边界的缺口，不增加优化策略。

## 实验决定

- 目录继续调用原索引，不重写匹配算法。一个实验分区仅接受同一完整身份、worker 实例、publisher 代次、group 0 和 device tier。多分区注册与总预算属于生产设计待办，实验不能冒充完整 M2。
- 接收共同水位的完整拓扑快照及连续增量；恢复时撤销精确信任。旧连接、旧恢复任务不能安装新目录；缺口、冲突、缺父链或超预算保持 unknown。
- 元数据、历史拓扑、恢复队列、查询长度及同时存在的索引副本分别有界。重建只保留驻留块与必要祖先。查询持读锁且不暴露索引 Arc，避免任意读者长期保留旧视图；写锁内完成批次安装。锁等待及重建延迟需单独测量，不能据此承诺线上性能。
- 字节计数为适配器逻辑资源计费，索引内部与 allocator RSS 通过实际实验记录；没有硬 RSS 上限保证。生产接入需有跨分区总预算、解码前 payload 限制及进程级资源配置。
- 流式实验在既有 HTTP 路径增加可选的按消费进度直接拉取接缝，不创建中间队列或独立 producer。默认未安装扩展继续使用原行为；drop/超限释放本地 source，后端终止仍需独立确认，账本保留未知。空数据块不算进度，每次 poll 最多读取一个空块后让出执行权；持续空块不得绕过 idle 限制。idle 检查发生在响应体被消费时，不能承担客户端完全停止消费时的连接期限；宿主总请求期限和下游期限另行验收。

## 退出条件

目录通过完整/缺口恢复、父链、代次/身份、清空、预算和并发查询反例；长时间更替不再随历史数量持续增长。流式实验覆盖慢消费者、停滞、drop、错误和正常结束，记录最大缓冲与任务退出。若需要改索引内部算法、复制代理或大范围改宿主，先提交证据并与用户讨论。

实验结果用于决定接口和复用边界；真实 HUST wire 接线、MOD 启停、可靠请求结算和 NPU 性能收益仍单独验收。
