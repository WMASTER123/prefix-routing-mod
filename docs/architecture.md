# 架构基线

更新：2026-10-16。组件完成情况以[progress](progress.md)为准；[历史架构增量](architecture-history.md)保留各次实验边界。真实公开 HTTP、M1、Rust M7→原 M2、M3/M4/M5 与 HUST 终态的有限组合已通过，持久恢复/长期回收/生产启停仍待验收。详细功能需求仍在[总体规划](planning/前缀路由综合套件_总体架构与组件规划.md)。

## 目标与范围

接入已有华为Ascend同模型多副本服务，优化固定NPU/CPU/内存下同时满足TTFT、生成停顿和完成率的服务容量。强基线的实际不足由本机实验确定，不预设已有系统普遍失败；易安装、可诊断、有界开销和明确兼容范围也是交付目标。

首版一个外部Router宿主、多个独立推理副本；M1–M8是职责，不是八个网络服务。不做P/D、分层缓存、KV搬运、异构调度、引擎淘汰替换、模型部署平台或多Router高可用。

```text
客户端 -> M5原宿主HTTP -> M1特征 -> M4基础/优化策略 -> M3条件预记账 -> M5发送/SSE
                                     ^                       |             |
                              M2目录 / M3状态                +--真实终态--+
                                     ^
已有副本 -> M7版本/事件/健康/终态适配 -+

M6在请求链外校准、压测、复现；M8以后只发布可关闭、可过期的软亲和计划。
```

## 组件与复用

| 职责 | 输入/输出与唯一所有权 | 实现方向 |
|---|---|---|
| M1请求特征 | 完整模型/模板/分词身份、完整token/block特征及精度 | 复用本地tokenizer/template，不按请求远程分词 |
| M2目录 | 原生事件到连续驻留匹配、unknown/信任/恢复状态 | 复用固定Router原索引，Directory/Pool补父链/预算/时效；不增加第二套树 |
| M3状态与账本 | 实例健康、控制版本、预留、在途及可靠对账的唯一写入者 | 复用基础健康与计数，补本项目条件预记账/可靠结算；生产持久化尚待测量选择 |
| M4选点 | 只读特征、目录、状态和可选软计划，输出带实例/版本的决定 | 先复用基础策略建立闭环，之后逐项测增量 |
| M5执行 | 接入、实际发送、传输生命周期的唯一来源 | 复用Router91b65ee的HTTP/SSE；保留已审窄幅接缝及关闭回退 |
| M6评测 | 负载、故障、校准到可复现报告 | 复用工具，补统一口径和配对消融 |
| M7宿主/MOD | 固定后端能力、事件/终态、版本差异与合法交付 | 集中profile映射；必要的小型只读包装默认关闭、固定守卫 |
| M8后台亲和 | 有界历史到版本化软偏好 | 后置；净收益成立才开启，不控制引擎淘汰或迁移 |

在线事件/健康/终态更新必须及时处理，不属于可延迟的M8慢路径。快慢分离是控制成本的结构，不单独宣称创新或性能优势。

## 必须保持的边界

- M4选点不修改目录或账本；M3 reserve成功才可发送，发送前复核配置/实例与排空。已发但结果未知不能自动重发或清零。
- HTTP EOF、错误或取消只是传输证据。完整family关联和真实核心逻辑终态才支持对账；逻辑终态不等同于KV/HBM已释放，业务结果另记。
- 服务实例与publisher/连接代次分开。目录失效只撤销精确缓存信任，不清除M3负债；普通帧不能恢复已失效目录。
- 身份、block/rank、连续事件、父链和观测时效均满足才提供observed匹配；unknown不冒充0。只计连续完整块，匹配量与实际节省工作量分开。
- 同进程读取是生产目标；请求不等待目录重建、M8计算或在线profile采样。解码、事件队列、查询、索引和历史有上限；重建暂态与全池预算共同计费。
- 配置原子发布；指标标签/日志有界，默认不保存提示原文。惰性导入不加载torch、初始化设备或启动线程/网络。

## 当前接线与生产形态的差别

Python包已有规范描述、配置预检、合同参考、固定版本适配和可选终态观测。Rust experiments直接调用原Router/原索引；Python工具作为有限supervisor持有原参考账本，验证跨进程真实语义。

在线目录实验使用同一个常驻原索引进程，异步订阅持续写入；stdio是资格验证接线，不是第二个生产索引服务。受控空起点支持新版原生三帧；无后端epoch/完整token快照时，不承诺已热接管、超窗或任意重启恢复。

原公开 HTTP 入口与 M1/M2/M3 本地绑定已通过真实 HUST 有限链；生产账本持久提交/游标、健康新鲜度、源端 GC、崩溃恢复与 MOD 完整启停尚未验收。example 不直接作为生产 ABI；按[持久恢复实现包](planning/durable-runtime-and-retention.md)完成后再冻结目录和接口，MOD 仍 import_only。

## Ascend与兼容

当前已验核心ced6857/Ascend b47795c，Qwen2.5-14B、FP16/eager、TP1/DP1、group0/block128。版本profile只说明经过哪些源码/运行检查，不接受任意vLLM版本；升级时增加映射、语义fixture与实机资格，不能仅改版本字符串。

设备无关的HTTP、分词与CPU索引继续复用；有效缓存收益、图/shape影响、KV容量和aarch64 Host竞争在目标配置校准。禁止照搬GPU成本系数或逐请求设备同步/npu-smi。语义兼容域、缓存布局/事件协议、执行性能指纹分别失效，见[Ascend设计](ascend-design.md)。

兼容矩阵、合同、事件限制分别见[compatibility](compatibility.md)、[contracts](contracts.md)、[KV合同](kv-event-contract.md)。最终用户交付目标是预构建制品、最小配置、doctor、启动/关闭说明与基础策略回退；当前尚无完整Manager激活或性能资格。
